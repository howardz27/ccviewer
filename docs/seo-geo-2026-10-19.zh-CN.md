## 本次范围

本地构建覆盖 10 种语言、60 个规范页面。本次不改变已有域名、301 规则或 Clarity 加载策略。下面的站外 Gist 已实际发布。站点采用 GitHub main 分支触发 Cloudflare 自动部署；本次优化通过该流程发布，部署成功以 Cloudflare 就绪状态和线上验收为准。

- 修复页面初始化把 SEO 标题覆盖成通用标题的问题，并加入运行时回归检查。
- 统一工具页 title、description、Open Graph；减少重复关键词和绝对隐私承诺，允许大图搜索预览。
- 建立 Organization / WebSite / WebPage / CollectionPage 的稳定标识，关联 WebApplication、源码和许可。保留 Article、BreadcrumbList 与可见 FAQ 一致的标记，不承诺富媒体展示。
- 修复 Article dateModified、可见 time、帮助目录日期、sitemap lastmod 的一致性。日期由编辑记录控制，不随每次构建刷新。
- 重写中英文 8 篇指南：直接回答、分清阅读/查找/存储/选择工具四类意图，补充 Windows PowerShell、WSL、自定义目录、保留策略、数据缺失和统计边界。
- 其余语言修正本地存储、完整保存、隐私和比较作者身份的关键表述；保留现有翻译的其他内容，仍适合后续母语编辑复核。
- 40 篇文章增加章节目录与锚点，去掉相关阅读中的自身链接。中英文文章有可见来源与对应 citation。
- 截图声明实际宽高比、懒加载和异步解码，避免图片加载时撑开文章；没有用未经测量的 Core Web Vitals 提升数字作宣传。
- 增加不含真实数据的 `assets/example-session.jsonl`，能对照工具调用、结果、Markdown 与示例用量；README 加入指南入口。
- 构建生成 `llms.txt`，作为可选的纯文本导航。它不替代 HTML、sitemap、robots，也不是搜索收录或 AI 引用保证。没有添加特定 AI 爬虫封禁规则。

## 验收与发布后检查

```sh
python3 claude-code-session-viewer/build.py
python3 tests/check_pages.py
node tests/analytics.cjs
node tests/seo-runtime.cjs
```

静态检查覆盖 60 页标题、描述、JSON-LD、规范地址、11 个 reciprocal hreflang、内部链接、章节锚点、可见引用、日期与 sitemap、llms.txt 目标。Analytics 检查确保统计行为未被这次 SEO 修改改变。另在浏览器核验中文文章、初始标题和虚构样例导入。浏览器下载事件等待超时，未把文件下载完成算作已验证；自动化检查已验证该样例的 Markdown 生成内容。

发布时将源码及生成产物一并提交并推送到 GitHub main，由已绑定的 Cloudflare 自动部署。发布内容包含生成 HTML、`sitemap.xml`、`_redirects`、`llms.txt` 和示例资源；`.assetsignore` 继续排除源码、测试和证据文档。发布后执行 `python3 tests/check_routing.py --base https://ccviewer.top`，确认新资源 200、规范页 200、旧地址 301、未知地址 404，再对重点中英文规范页面检查索引。

评估时比较相同日期长度的非品牌搜索展示、点击、实际导入/导出事件、Gist 引荐访问与可核验的 AI 引用。先积累基线，不虚构增长幅度。若要持续监测，需另行设置监测任务；本次未创建自动化。
