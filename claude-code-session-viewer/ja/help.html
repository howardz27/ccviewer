セッションの JSONL ファイルの場所を探す方法
Claude Code のセッションファイルは ~/.claude/projects//.jsonl にあります。find/grep でセッションの JSONL ファイルを素早く特定する方法と、sessionId が分からないときに内容や時刻から逆引きする方法を解説。

Claude Code のセッション履歴はどこに保存される？
Claude Code はセッション履歴を ~/.claude/projects/ 配下に JSONL ファイルとしてローカル保存します — クラウド同期なし。ディレクトリ構造、各行 JSON のフィールド（message/timestamp/usage/gitBranch）、バックアップのアドバイ…

2026 年のベストな Claude Code セッションビューアは？
2026 年に Claude Code セッション履歴を振り返る主な方法を比較：内蔵の claude --resume、コマンドラインの jq/grep、汎用 JSONL ツール、そしてオープンソースのグラフィカルビューア CCViewer — 機能・プライバシー・使いやすさから推奨を提示。

CCViewer で Claude Code セッションをビジュアルに再生
ページを開いて .jsonl ファイル（または ~/.claude/projects/ フォルダ全体）をドロップするだけ。Markdown レンダリング、思考ブロック、ツール呼び出し、トークン・コスト統計まで、すべてブラウザ内のローカル処理で、データは送信されません。
