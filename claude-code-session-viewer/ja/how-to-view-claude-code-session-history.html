Claude Code セッションの完全な履歴を表示するには？

更新日 2026-10-12 · CCViewer ヘルプセンター · Claude Code 2.x 対応

Claude Code はすべてのセッションをローカルディスクに完全に記録します。履歴を表示する主な方法は 3 つあり、使いやすさ順に紹介します。

方法 1：CCViewer でブラウザにビジュアル再生（推奨）

CCViewer は無料・オープンソースの Claude Code セッションビューアです。ページを開き、セッションファイルをドロップする（~/.claude/projects/ フォルダ全体を取り込むことも可能）だけで、チャット履歴のようにセッションを再生できます：

  • 完全な Markdown 描画 — コードブロック・表・リスト・リンクをそのまま表示。長い JSON の羅列とはおさらば；
  • 思考ブロック — モデルの拡張推論をワンクリックで折りたたみ／展開；
  • ツール呼び出し — Read / Edit / Bash などの各呼び出しのパラメータと結果を展開して確認可能；
  • 使用量・コスト統計 — 入力/出力/キャッシュトークン、セッション時間、増減行数、合計コストを一覧；
  • Markdown エクスポート — 任意のセッションをワンクリックで共有可能な .md ドキュメントに。

何より、解析と描画が 100% ブラウザ内で完結し、何もアップロードされません。セッションファイルにはソースコード・ファイルパス・場合によってはシークレットが含まれるため、これは重要です。

方法 2：端末でセッションを再開

Claude Code にはセッション再開機能が組み込まれています。元のプロジェクトディレクトリで実行します：

# このプロジェクトのセッション一覧を表示し、対話的に選択
claude --resume     # 短縮形: claude -r

# 最新セッションを直接再開
claude --continue   # 短縮形: claude -c

# セッション ID を指定して再開
claude --resume <sessionId>

「作業を続ける」用途には最適ですが、履歴の閲覧・検索には不便です。長いセッションから特定のツール呼び出しを探すのは大変で、コスト統計もありません。

方法 3：生の JSONL ファイルを読む

セッションは ~/.claude/projects/<project>/<sessionId>.jsonl に JSONL 形式（1 行 1 JSON オブジェクト）で保存されます。任意のエディタやコマンドで確認できます：

# jq で全ユーザープロンプトを抽出
cat ~/.claude/projects/-Users-you-myproject/<sessionId>.jsonl \\
  | jq -r 'select(.type=="user") | .message.content'

生ファイルは最も完全な情報源（トークン使用量・git ブランチ・タイムスタンプ等のメタデータ含む）ですが、可読性は低い — まさにグラフィカルビューアが存在する理由です。

よくある質問

履歴を表示するとコードはアップロードされますか？
されません。CCViewer の解析と描画はすべてブラウザ内で行われ、セッション内容を送信するネットワーク通信は一切ありません。開発者ツールの Network パネルで自分で検証できます。
セッション内の圧縮（compact）された部分も見られますか？
見られます。圧縮サマリーとそれ以降のメッセージは同じ JSONL ファイルに記録されており、ビューアはサマリーを注入コンテキストとして表示します。「システム/注入」トグルで確認できます。
スマートフォンでも使えますか？
使えます。CCViewer はレスポンシブなウェブページです。ただしセッションファイルは PC 上にあるため、まず .jsonl をスマホに転送（iCloud など）してからブラウザで開く必要があります。
