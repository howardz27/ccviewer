Claude Code セッションの履歴はどこに保存されますか？

更新日 2026-10-12 · CCViewer ヘルプセンター · Claude Code 2.x 対応

簡潔に答えると：すべて ~/.claude/projects/ 配下に JSONL ファイルとしてローカル保存されます。クラウド同期も、アカウント紐付けのセッション履歴もありません。

ディレクトリ構造

~/.claude/
├── projects/                     # ← すべてのセッション履歴はここ
│   ├── -Users-you-Documents-app/ #   プロジェクトごとに 1 ディレクトリ（パス変換）
│   │   ├── 9a1b2c3d-….jsonl     #     セッションごとに 1 ファイル
│   │   └── 7c2d3e4f-….jsonl
│   └── -home-you-shop-api/
│       └── …
├── claude.json                   # グローバル設定（MCP、テーマ、プロジェクト状態）
└── …（キャッシュ、ログ、統計などの補助ファイル）

プロジェクトディレクトリ名の規則：プロジェクトパス中の /、_ などの非英数字が - に置換される。そのため同じプロジェクトのセッションはすべて同じディレクトリに集まります — 各種ビューアの「プロジェクト別グループ化」の根拠もこれです。

JSONL ファイルの中身

JSONL = 1 行 1 個の独立した JSON オブジェクト。セッションファイルは時系列で完全な対話を記録します。主なエントリ型：

type内容
userあなたの入力（テキスト / 画像）とツール実行結果の返却
assistantモデルの応答：本文、思考ブロック、tool_use 呼び出しとトークン使用量
systemシステムイベント（hooks など）
summary / ai-titleセッションサマリーと自動生成タイトル
cost-stateコスト・使用量スナップショット（合計コスト、増減行数、API 時間）

各エントリには timestamp、cwd（プロジェクトパス）、gitBranch、version、sessionId などのメタデータも付きます。つまり履歴ファイルは端末の表示より完全です — 思考過程、ツール呼び出しの生パラメータと結果、トークン消費がすべて記録されています。

これが意味すること

  • プライバシーは自分の手の中：ファイルは PC から出ません。逆に言えば、PC 交換・リインストール前に ~/.claude/projects/ をバックアップしないと履歴は失われます；
  • ファイルは機密になりうる：セッションにはソースコード断片、ファイルパス、コマンド出力、時にはシークレットが含まれます — .jsonl を気軽に共有・公開しないこと；
  • サイズは増える：数ヶ月ヘビーに使うと 1 セッションが数 MB〜数十 MB、ディレクトリ全体で数百 MB になるのは普通です。

この履歴を快適に読むには

生の JSONL を読むのは骨が折れます。CCViewer でディレクトリを開く（フォルダごとドロップ可能）と、セッションはプロジェクト別にグループ化され、Markdown・思考ブロック・ツール呼び出し・コスト統計がすべてグラフィカルに描画されます — 解析はブラウザ内のみで行われ、「データは PC の外に出ない」性質は変わりません。

CCViewer で Claude Code セッションをビジュアルに再生
ページを開いて .jsonl ファイル（または ~/.claude/projects/ フォルダ全体）をドロップするだけ。Markdown レンダリング、思考ブロック、ツール呼び出し、トークン・コスト統計まで、すべてブラウザ内のローカル処理で、データは送信されません。

よくある質問

Claude Code の履歴は Anthropic のサーバーにアップロードされますか？
セッションファイル自体はローカルの ~/.claude/projects/ に保存され、クラウドに別途保存されることはありません。もちろん会話の発生中は内容が API 経由で処理されます（モデル利用の前提）が、「履歴ファイル」はあなたが完全に管理するローカルファイルです。
セッション履歴の削除方法は？
対応する .jsonl ファイル（またはプロジェクトのサブディレクトリ全体）を削除するだけです。resume 一覧からも消えます。削除前にバックアップが不要か確認してください。
~/.claude/projects と ~/.claude.json は同じもの？
違います。~/.claude.json（または claude.json）はグローバル設定ファイル（MCP サーバー、テーマなど）。セッション履歴は ~/.claude/projects/ 配下の .jsonl ファイルにあります。
