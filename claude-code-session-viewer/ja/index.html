よくある質問

Claude Code の過去セッションを表示するには？
ローカルセッションの既定の保存先は ~/.claude/projects/ です。CLAUDE_CONFIG_DIR を設定すると基準ディレクトリが変わります。保存の無効化や保持期間による削除があるため、すべての履歴が永久に残るとは限りません。クラウドやリモート環境では実行場所を確認してください。
セッションファイルはアップロードされますか？
セッションファイルはブラウザ内で解析・表示されます。公開サイトでは Microsoft Clarity を自動で読み込み、ページ操作を記録します。オフライン版では解析を読み込みません。
ビューアは何に対応していますか？
ユーザーとアシスタントのメッセージの Markdown レンダリング、extended thinking の思考ブロック、ツール呼び出しのパラメータと結果、画像、トークン使用量とコスト統計に対応し、多言語インターフェースも切替可能です。
.jsonl とはどんな形式ですか？
JSON Lines — 1 行に 1 つの独立した JSON オブジェクトが入る形式です。Claude Code はメッセージ・ツール呼び出し・メタデータを 1 行ずつ記録します。
CCViewer は無料ですか？
無料でオープンソースです。登録やログインは不要で、ブラウザから直接利用できます。
