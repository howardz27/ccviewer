Как посмотреть полную историю сессии Claude Code?

Обновлено 2026-10-19 · CCViewer Центр справки · Подходит для Claude Code 2.x

Локальные сессии по умолчанию находятся в ~/.claude/projects/. CLAUDE_CONFIG_DIR меняет базовый каталог. Сохранение может быть отключено, а правила хранения могут удалять файлы: история не обязательно остаётся навсегда. Для облачных и удалённых сессий проверьте среду выполнения.

  • Способ 1: визуально воспроизвести в браузере с CCViewer (рекомендуется)
  • Способ 2: возобновить сессию в терминале
  • Способ 3: читать сырой JSONL-файл
  • Сравнение

Способ 1: визуально воспроизвести в браузере с CCViewer (рекомендуется)

CCViewer — бесплатный открытый просмотрщик сессий Claude Code. Откройте страницу, перетащите файл сессии (можно выбрать и всю папку ~/.claude/projects/) и листайте сессию как чат:

  • Полный рендеринг Markdown — блоки кода, таблицы, списки и ссылки как есть, без стен JSON;
  • Блоки размышлений — расширенное рассуждение модели, сворачивается одним кликом;
  • Вызовы инструментов — параметры и результаты каждого вызова Read / Edit / Bash, раскрываются для проверки;
  • Статистика использования и расходов — токены ввода/вывода/кэша, длительность сессии, добавленные/удалённые строки, общая стоимость — всё наглядно;
  • Экспорт в Markdown — любая сессия одним кликом превращается в готовый к шарингу .md-документ.

Файлы сеансов обрабатываются и отображаются локально в браузере. Сайт автоматически загружает Microsoft Clarity для записи взаимодействий со страницей. Офлайн-копии не загружают аналитику.

Способ 2: возобновить сессию в терминале

В Claude Code встроено возобновление сессий. Выполните в исходном каталоге проекта:

# Показать сессии проекта и выбрать интерактивно
claude --resume     # сокращение: claude -r

# Сразу возобновить последнюю сессию
claude --continue   # сокращение: claude -c

# Возобновить конкретную сессию по ID
claude --resume <sessionId>

Отлично для «продолжить работу», но неудобно для чтения и поиска по истории: выуживать один вызов инструмента из длинной сессии мучительно, статистики расходов тоже нет.

Способ 3: читать сырой JSONL-файл

Сессии хранятся в JSONL по пути ~/.claude/projects/<проект>/<sessionId>.jsonl — по одному JSON-объекту на строку. Смотреть можно любым редактором или командной строкой:

# Извлечь все вопросы пользователя через jq
cat ~/.claude/projects/-Users-you-myproject/<sessionId>.jsonl \\
  | jq -r 'select(.type=="user") | .message.content'

Сырой файл — самый полный источник (расход токенов, ветка git, метки времени и другие метаданные), но читаемость низкая — ровно поэтому и существуют графические просмотрщики.

Частые вопросы

Загружается ли мой код при просмотре истории?
Файлы сеансов обрабатываются и отображаются локально в браузере. Сайт автоматически загружает Microsoft Clarity для записи взаимодействий со страницей. Офлайн-копии не загружают аналитику.
Видны ли сжатые (compact) части сессии?
JSONL содержит одно значение JSON на строку. CCViewer показывает поддерживаемые сообщения и вызовы инструментов, оставшиеся в файле. Он не восстанавливает отсутствующие или удалённые записи; статистика зависит от доступных полей. Сохраняйте исходные файлы.
Работает ли на телефоне?
Да — CCViewer адаптивная веб-страница. Но файлы сессий лежат на компьютере: сначала скопируйте .jsonl на телефон (например, через iCloud/облако) и откройте в браузере.
