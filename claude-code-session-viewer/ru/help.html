Визуально воспроизводите сессии Claude Code с CCViewer
Откройте страницу и перетащите файл .jsonl — или всю папку ~/.claude/projects/. Markdown, блоки размышлений, вызовы инструментов, статистика токенов и расходов — всё обрабатывается локально в браузере, ничего не отправляется.
