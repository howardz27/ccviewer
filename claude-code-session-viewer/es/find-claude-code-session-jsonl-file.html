¿Cómo encuentro la ubicación del archivo JSONL de una sesión de Claude Code?

Actualizado 2026-10-19 · CCViewer Centro de ayuda · Aplica a Claude Code 2.x

La ruta predeterminada de las sesiones locales es ~/.claude/projects/. CLAUDE_CONFIG_DIR cambia el directorio base. La persistencia puede desactivarse y la retención puede eliminar archivos; no se conserva necesariamente todo para siempre. Comprueba el entorno de ejecución en sesiones remotas o en la nube.

Primero, entiende la nomenclatura de directorios

Cada subdirectorio de ~/.claude/projects/ corresponde a un proyecto (directorio de trabajo). El nombre se deriva de la ruta del proyecto: los caracteres /, _ y demás no alfanuméricos se sustituyen por guiones -. Por ejemplo:

Ruta del proyecto                Directorio de sesión
/Users/you/Documents/my_app      →  -Users-you-Documents-my-app
/home/you/projects/shop-api      →  -home-you-projects-shop-api

Cada sesión es un archivo: <sessionId>.jsonl (un UUID como 9a1b2c3d-…).

Caso 1: conoces el sessionId — find directo

find ~/.claude/projects -name "<sessionId>.jsonl"

¿De dónde sale el sessionId? Lo más fácil es escribir el comando de barra /status en la conversación — la salida incluye el Session ID actual. También lo obtienes de la lista de claude --resume, de mensajes de error o del campo «Session ID» de la barra lateral del visor.

Caso 2: sin sessionId — buscar por contenido

Si recuerdas algo de la conversación (p. ej. tu pregunta original), haz grep:

# Buscar una palabra clave en todas las sesiones y listar los archivos
grep -l "arreglar la página de login" ~/.claude/projects/*/*.jsonl

# Buscar solo en un directorio de proyecto
grep -l "arreglar la página de login" ~/.claude/projects/-Users-you-Documents-my-app/*.jsonl

Caso 3: encontrar sesiones recientes por fecha

# Listar los 10 archivos de sesión modificados más recientemente
ls -t ~/.claude/projects/*/*.jsonl | head -10

Consejos macOS: abrir carpetas ocultas

  • En Finder pulsa ⌘⇧G, escribe ~/.claude/projects y Enter;
  • En diálogos de archivo pulsa ⌘⇧. para mostrar carpetas ocultas (los directorios que empiezan por . son invisibles por defecto).

Preguntas frecuentes

¿Por qué no encuentro el directorio ~/.claude?
Porque empieza con un punto y está oculto por defecto. En Finder pulsa ⌘⇧G y escribe la ruta, o ⌘⇧. para mostrar archivos ocultos; en la terminal, ls -la ~/.claude siempre funciona.
Hay muchos jsonl en un proyecto — ¿cuál es el mío?
Un archivo equivale a una sesión. Filtra por fecha de modificación (ls -t) o contenido (grep -l); o importa la carpeta completa con CCViewer, que muestra el título y estadísticas de cada sesión para distinguirlas de un vistazo.
¿Cuál es la ruta en Windows?
La misma estructura bajo tu perfil de usuario: %USERPROFILE%\\.claude\\projects\\<proyecto>\\<sessionId>.jsonl.
