¿Dónde se guarda el historial de las sesiones de Claude Code?

Actualizado 2026-10-12 · CCViewer Centro de ayuda · Aplica a Claude Code 2.x

Respuesta corta: todo se guarda localmente bajo ~/.claude/projects/ como archivos JSONL — sin sincronización en la nube ni historial de sesiones ligado a la cuenta.

Estructura de directorios

~/.claude/
├── projects/                     # ← aquí vive todo el historial
│   ├── -Users-you-Documents-app/ #   un directorio por proyecto (ruta transformada)
│   │   ├── 9a1b2c3d-….jsonl     #     un archivo por sesión
│   │   └── 7c2d3e4f-….jsonl
│   └── -home-you-shop-api/
│       └── …
├── claude.json                   # configuración global (MCP, tema, estado por proyecto)
└── … (caché, logs, estadísticas y otros archivos auxiliares)

Regla de nombres de los directorios de proyecto: todo carácter no alfanumérico (/, _, …) de la ruta se convierte en -. Así, todas las sesiones de un proyecto se agrupan en un mismo directorio — de ahí que los visores puedan «agrupar por proyecto».

Qué hay dentro de un archivo JSONL

JSONL = un objeto JSON independiente por línea. Un archivo de sesión registra la conversación completa en orden cronológico. Tipos principales de entrada:

typeContenido
userTu entrada (texto / imágenes) y los resultados de herramientas devueltos
assistantRespuestas del modelo: texto, bloques de pensamiento, llamadas tool_use y uso de tokens
systemEventos del sistema (hooks, etc.)
summary / ai-titleResumen de sesión y título autogenerado
cost-stateInstantánea de coste y uso (coste total, líneas ±, duración de API)

Cada entrada incluye metadatos: timestamp, cwd (ruta del proyecto), gitBranch, version, sessionId, etc. Es decir, el archivo de historial es más completo que lo que muestra la terminal — el razonamiento, los parámetros y resultados crudos de cada herramienta y el consumo de tokens están ahí dentro.

Qué significa para ti

  • La privacidad está en tus manos: los archivos nunca salen de tu máquina. A cambio, haz copia de seguridad de ~/.claude/projects/ antes de cambiar de ordenador o reinstalar, o el historial se pierde;
  • Los archivos pueden ser sensibles: las sesiones contienen fragmentos de código fuente, rutas, salida de comandos e incluso secretos — no compartas .jsonl a la ligera ni los publiques;
  • El tamaño crece: tras meses de uso intensivo, una sesión puede alcanzar varios (o decenas de) MB y el directorio completo cientos de MB — es normal.

Cómo leer este historial con comodidad

Leer JSONL en bruto es una paliza. Abre el directorio con CCViewer (admite arrastrar la carpeta completa): las sesiones se agrupan por proyecto y Markdown, bloques de pensamiento, llamadas a herramientas y estadísticas de coste se renderizan gráficamente — con el análisis ocurriendo solo en tu navegador, preservando la propiedad «los datos nunca salen de esta máquina».

Preguntas frecuentes

¿Se sube el historial de Claude Code a los servidores de Anthropic?
Los archivos de sesión permanecen en el ~/.claude/projects/ local y no se almacenan aparte en la nube. Por supuesto, mientras ocurre una conversación su contenido se procesa vía API — es inherente al uso del modelo —, pero los archivos de historial son archivos locales bajo tu control total.
¿Cómo borro el historial de sesiones?
Simplemente elimina el archivo .jsonl correspondiente (o el subdirectorio completo del proyecto); la sesión desaparece de la lista de resume. Asegúrate antes de no necesitar una copia.
¿Son lo mismo ~/.claude/projects y ~/.claude.json?
No. ~/.claude.json (o claude.json) es el archivo de configuración global (servidores MCP, tema, etc.); el historial de sesiones vive en los .jsonl bajo ~/.claude/projects/.
