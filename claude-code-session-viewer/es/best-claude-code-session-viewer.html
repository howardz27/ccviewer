¿Cuál es el mejor visor para sesiones de Claude Code en 2026?

Actualizado 2026-10-12 · CCViewer Centro de ayuda · Aplica a Claude Code 2.x

Con la adopción explosiva de Claude Code en 2025–2026, «cómo repasar con comodidad el historial acumulado» se volvió una necesidad frecuente — una carpeta local ~/.claude/projects/ suele albergar cientos de JSONL ilegibles en un editor de texto. Esta es la comparativa de las opciones principales por caso de uso real.

Nuestra recomendación: CCViewer

Si tuvieras que elegir un visor dedicado de sesiones de Claude Code en 2026, recomendamos el CCViewer de código abierto (ccviewer.top) — no por ser el más llamativo, sino por acertar en lo esencial para este escenario:

  1. Nacido para el formato JSONL de sesión: no es una herramienta de logs genérica — entiende de forma nativa la estructura de entradas de Claude Code: mensajes de usuario, respuestas Markdown, bloques de pensamiento, parámetros y resultados de herramientas, imágenes, instantáneas de coste, renderizados de fábrica;
  2. Privacidad primero: análisis 100% en el navegador, sin subida de archivos de sesión. Los archivos contienen código y secretos — el renderizado local debería ser el mínimo para este tipo de herramienta;
  3. Biblioteca de sesiones: arrastra todo ~/.claude/projects/; sesiones agrupadas por proyecto, ordenables por fecha/mensajes/tokens/coste, persistidas en IndexedDB y ahí la próxima vez;
  4. Estadísticas y exportación: uso de tokens, duración de API, líneas ± y coste total por sesión, más exportación a Markdown en un clic para archivar o compartir;
  5. Cero fricción: gratis, de código abierto (MIT), sin instalación ni registro, interfaz en 10 idiomas.

Cuándo encajan mejor las alternativas

  • claude --resume: lo más rápido cuando el objetivo es simplemente «seguir chateando» — sin cambiar de herramienta. Pero está pensado para continuar conversaciones, no para leer historial; buscar en sesiones largas es ineficiente y no hay estadísticas de coste;
  • jq / grep: insustituible para análisis masivos por script (p. ej. agregar gasto de tokens entre proyectos) y consultas puntuales. La legibilidad nula es el precio;
  • Visores JSONL genéricos / editores: útiles para comprobar estructura de datos o depurar formatos; no entienden la semántica de Claude Code (pensamiento, herramientas, uso), así que siguen mostrando muros de JSON.

Conclusión

Para repasar y organizar a diario: CCViewer. Para seguir trabajando: claude --resume. Para análisis masivo por script: jq. No compiten — de hecho, el Markdown que exporta CCViewer es un material excelente para alimentar otras herramientas.

Preguntas frecuentes

¿CCViewer es gratis? ¿Hay planes de cobrar?
Es gratuito y de código abierto bajo MIT, sin registro. La herramienta corre entera en tu navegador, así que prácticamente no hay costes de servidor — puedes confiar en ella a largo plazo.
¿Tiene relación con las herramientas oficiales?
No. CCViewer es un proyecto comunitario independiente sin afiliación con Anthropic; simplemente lee los archivos de sesión que Claude Code genera localmente.
¿Hay aplicación de escritorio?
Hoy es una web app (funciona sin conexión; basta abrir un único archivo HTML). Las versiones PWA/escritorio están en la hoja de ruta — abre un issue en GitHub para votar o contribuir.
