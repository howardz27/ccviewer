¿Cómo veo el historial completo de una sesión de Claude Code?

Actualizado 2026-10-12 · CCViewer Centro de ayuda · Aplica a Claude Code 2.x

Claude Code registra cada sesión por completo en tu disco local, así que hay tres formas principales de ver el historial, ordenadas por facilidad de uso.

Método 1: Reproducirla visualmente en el navegador con CCViewer (recomendado)

CCViewer es un visor de sesiones de Claude Code gratuito y de código abierto. Abre la página, suelta un archivo de sesión (también puedes elegir la carpeta ~/.claude/projects/ completa para importarlo todo) y reproduce la sesión como si fuera un chat:

  • Renderizado Markdown completo — bloques de código, tablas, listas y enlaces tal cual; se acabaron los muros de JSON;
  • Bloques de pensamiento — el razonamiento extendido del modelo, plegable con un clic;
  • Llamadas a herramientas — parámetros y resultados de cada llamada Read / Edit / Bash, desplegables para inspección;
  • Estadísticas de uso y coste — tokens de entrada/salida/caché, duración de la sesión, líneas añadidas/eliminadas y coste total de un vistazo;
  • Exportación a Markdown — convierte cualquier sesión en un documento .md compartible con un clic.

Lo crucial: analiza y renderiza todo al 100% en tu navegador — no se sube nada. Y eso importa: los archivos de sesión contienen tu código fuente, rutas de archivo y a veces secretos.

Método 2: Reanudar la sesión en la terminal

Claude Code incluye reanudación de sesiones. Ejecuta esto en el directorio original del proyecto:

# Listar las sesiones del proyecto y elegir una interactivamente
claude --resume     # abreviatura: claude -r

# Reanudar directamente la sesión más reciente
claude --continue   # abreviatura: claude -c

# Reanudar una sesión concreta por ID
claude --resume <sessionId>

Perfecto para «seguir trabajando», pero incómodo para leer o buscar en el historial: revolver una sesión larga buscando una llamada a herramienta es un suplicio, y no hay estadísticas de coste.

Método 3: Leer el archivo JSONL en bruto

Las sesiones se guardan como JSONL en ~/.claude/projects/<proyecto>/<sessionId>.jsonl — un objeto JSON por línea. Puedes inspeccionarlas con cualquier editor o la línea de comandos:

# Extraer todos los prompts del usuario con jq
cat ~/.claude/projects/-Users-you-myproject/<sessionId>.jsonl \\
  | jq -r 'select(.type=="user") | .message.content'

El archivo en bruto es la fuente más completa (uso de tokens, rama de git, marcas de tiempo y otros metadatos), pero su legibilidad es pobre — exactamente la razón de ser de los visores gráficos.

Preguntas frecuentes

¿Ver el historial sube mi código?
No. CCViewer analiza y renderiza todo en tu navegador; ninguna petición de red lleva contenido de la sesión. Puedes verificarlo tú mismo en el panel Network de las DevTools.
¿Puedo ver las partes compactadas de una sesión?
Sí. Los resúmenes de compactación y los mensajes posteriores viven en el mismo archivo JSONL; el visor muestra los resúmenes como contexto inyectado, visible con el interruptor «Sistema/Inyectado».
¿Funciona en el móvil?
Sí — CCViewer es una página web responsive. Eso sí, los archivos de sesión están en tu ordenador: primero copia el .jsonl al teléfono (p. ej. vía iCloud/Drive) y ábrelo en un navegador.
