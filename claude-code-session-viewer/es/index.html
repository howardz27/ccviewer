Preguntas frecuentes

¿Cómo veo sesiones anteriores de Claude Code?
Claude Code guarda cada sesión como un archivo JSONL en ~/.claude/projects/<proyecto>/<session-id>.jsonl. Suelta ese archivo en esta página para explorar la conversación completa.
¿Se sube mi archivo de sesión a algún sitio?
No. El análisis ocurre íntegramente en tu navegador, sin llamadas de red ni subidas al servidor. Los archivos de sesión contienen tu código y rutas de archivos; por eso esta herramienta es 100% de cliente.
¿Qué admite el visor?
Markdown para mensajes del usuario y del asistente, bloques de extended thinking, parámetros y resultados de herramientas, imágenes, uso de tokens y estadísticas de coste, con interfaz en 10 idiomas.
¿Qué es el formato .jsonl?
JSON Lines: un objeto JSON independiente por línea. Claude Code registra cada mensaje, llamada a herramienta y metadato como una línea.
¿Es gratis CCViewer?
Sí, es gratuito y de código abierto. No requiere registro.
