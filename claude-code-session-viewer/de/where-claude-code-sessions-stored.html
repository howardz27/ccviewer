Wo werden die Verlaufsinformationen von Claude-Code-Sessions gespeichert?

Aktualisiert 2026-10-12 · CCViewer Hilfe-Center · Gilt für Claude Code 2.x

Kurze Antwort: alles liegt lokal unter ~/.claude/projects/ als JSONL-Dateien — kein Cloud-Sync, kein kontobasierter Sitzungsverlauf.

Verzeichnisstruktur

~/.claude/
├── projects/                     # ← hier liegt der gesamte Sitzungsverlauf
│   ├── -Users-you-Documents-app/ #   ein Verzeichnis pro Projekt (Pfad-umgewandelt)
│   │   ├── 9a1b2c3d-….jsonl     #     eine Datei pro Session
│   │   └── 7c2d3e4f-….jsonl
│   └── -home-you-shop-api/
│       └── …
├── claude.json                   # globale Konfiguration (MCP, Theme, Projektzustand)
└── … (Cache, Logs, Statistiken und weitere Hilfsdateien)

Namensregel der Projektverzeichnisse: jedes nicht-alphanumerische Zeichen (/, _, …) im Projektpfad wird zu -. Daher bündeln sich alle Sessions eines Projekts in einem Verzeichnis — die Grundlage für das „Gruppieren nach Projekt“ der Viewer.

Was in einer JSONL-Datei steckt

JSONL = ein unabhängiges JSON-Objekt pro Zeile. Eine Session-Datei hält die komplette Konversation in chronologischer Reihenfolge fest. Wichtigste Eintragstypen:

typeInhalt
userDeine Eingaben (Text / Bilder) und zurückgegebene Tool-Ergebnisse
assistantModellantworten: Text, Thinking-Blöcke, tool_use-Aufrufe und Token-Nutzung
systemSystemereignisse (Hooks etc.)
summary / ai-titleSitzungszusammenfassung und automatisch erzeugter Titel
cost-stateKosten-/Nutzungs-Snapshot (Gesamtkosten, Zeilen ±, API-Dauer)

Jeder Eintrag trägt zudem Metadaten: timestamp, cwd (Projektpfad), gitBranch, version, sessionId usw. Das heißt: Die Verlaufsdatei ist vollständiger als die Terminal-Anzeige — Reasoning, rohe Tool-Parameter und -Ergebnisse sowie der Token-Verbrauch sind alle enthalten.

Was das für dich bedeutet

  • Privatsphäre liegt in deiner Hand: Die Dateien verlassen dein Gerät nie. Umgekehrt: vor Rechnerwechsel/Neuinstallation ~/.claude/projects/ sichern, sonst ist der Verlauf weg;
  • Dateien können sensibel sein: Sessions enthalten Quellcode-Schnipsel, Dateipfade, Kommandoausgaben, teils Secrets — .jsonl nicht achtlos weitergeben oder öffentlich posten;
  • Die Größe wächst: Nach Monaten intensiver Nutzung kann eine Session mehrere (zig) MB erreichen und das Gesamtverzeichnis hunderte MB — das ist normal.

Wie man diesen Verlauf bequem liest

Rohes JSONL zu lesen ist Qual. Öffne das Verzeichnis mit CCViewer (ganzer Ordner per Drag & Drop möglich): Sessions gruppieren sich nach Projekt, Markdown, Thinking-Blöcke, Tool-Aufrufe und Kostenstatistiken werden grafisch gerendert — das Parsing läuft ausschließlich lokal im Browser und bewahrt so die Eigenschaft „Daten verlassen diesen Rechner nie“.

Häufige Fragen

Wird der Claude-Code-Verlauf auf Anthropic-Server hochgeladen?
Die Session-Dateien selbst bleiben im lokalen ~/.claude/projects/ und werden nicht separat in der Cloud gespeichert. Natürlich wird der Inhalt während einer Konversation über die API verarbeitet — das ist inherent am Modellgebrauch —, aber die Verlaufsdateien sind lokale Dateien unter deiner vollständigen Kontrolle.
Wie lösche ich den Sitzungsverlauf?
Einfach die betreffende .jsonl-Datei (oder das ganze Projekt-Unterverzeichnis) löschen; die Session verschwindet dann auch aus der Resume-Liste. Vorher sichergehen, dass kein Backup gebraucht wird.
Sind ~/.claude/projects und ~/.claude.json dasselbe?
Nein. ~/.claude.json (bzw. claude.json) ist die globale Konfigurationsdatei (MCP-Server, Theme usw.); der Sitzungsverlauf liegt in den .jsonl-Dateien unter ~/.claude/projects/.
