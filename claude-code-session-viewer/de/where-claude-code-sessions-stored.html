Wo werden die Verlaufsinformationen von Claude-Code-Sessions gespeichert?

Aktualisiert 2026-10-19 · CCViewer Hilfe-Center · Gilt für Claude Code 2.x

Lokale Sitzungen liegen standardmäßig unter ~/.claude/projects/. CLAUDE_CONFIG_DIR ändert das Basisverzeichnis. Speicherung kann deaktiviert sein und Aufbewahrungsregeln können Dateien löschen; nicht jeder Verlauf bleibt dauerhaft verfügbar. Prüfe bei Cloud- oder Remote-Sitzungen die Ausführungsumgebung.

Format und Grenzen

JSONL enthält einen JSON-Wert pro Zeile. CCViewer zeigt unterstützte Nachrichten und Tool-Einträge, die in der Datei vorhanden sind. Fehlende oder gelöschte Daten lassen sich nicht wiederherstellen; Statistiken hängen von den verfügbaren Feldern ab. Bewahre Originaldateien auf.

Sitzungsdateien werden lokal im Browser verarbeitet und angezeigt. Die gehostete Website lädt Microsoft Clarity automatisch, um Seiteninteraktionen aufzuzeichnen. Offline-Kopien laden keine Analyse.

Häufige Fragen

Wird der Claude-Code-Verlauf auf Anthropic-Server hochgeladen?
Lokale Sitzungen liegen standardmäßig unter ~/.claude/projects/. CLAUDE_CONFIG_DIR ändert das Basisverzeichnis. Speicherung kann deaktiviert sein und Aufbewahrungsregeln können Dateien löschen; nicht jeder Verlauf bleibt dauerhaft verfügbar. Prüfe bei Cloud- oder Remote-Sitzungen die Ausführungsumgebung. Sitzungsdateien werden lokal im Browser verarbeitet und angezeigt. Die gehostete Website lädt Microsoft Clarity automatisch, um Seiteninteraktionen aufzuzeichnen. Offline-Kopien laden keine Analyse.
Wie lösche ich den Sitzungsverlauf?
Einfach die betreffende .jsonl-Datei (oder das ganze Projekt-Unterverzeichnis) löschen; die Session verschwindet dann auch aus der Resume-Liste. Vorher sichergehen, dass kein Backup gebraucht wird.
Sind ~/.claude/projects und ~/.claude.json dasselbe?
Nein. ~/.claude.json (bzw. claude.json) ist die globale Konfigurationsdatei (MCP-Server, Theme usw.); der Sitzungsverlauf liegt in den .jsonl-Dateien unter ~/.claude/projects/.
