Wie sehe ich den vollständigen Verlauf einer Claude-Code-Session?

Aktualisiert 2026-10-19 · CCViewer Hilfe-Center · Gilt für Claude Code 2.x

Lokale Sitzungen liegen standardmäßig unter ~/.claude/projects/. CLAUDE_CONFIG_DIR ändert das Basisverzeichnis. Speicherung kann deaktiviert sein und Aufbewahrungsregeln können Dateien löschen; nicht jeder Verlauf bleibt dauerhaft verfügbar. Prüfe bei Cloud- oder Remote-Sitzungen die Ausführungsumgebung.

  • Methode 2: Die Session im Terminal fortsetzen

  • Vergleich

Methode 1: Visuell im Browser mit CCViewer abspielen (empfohlen)

CCViewer ist ein kostenloser Open-Source-Session-Viewer für Claude Code. Seite öffnen, Session-Datei hineinziehen (auch der ganze Ordner ~/.claude/projects/ funktioniert) und die Session wie ein Chat-Protokoll abspielen:

  • Volles Markdown-Rendering — Code-Blöcke, Tabellen, Listen und Links wie im Original, Schluss mit JSON-Mauern;
  • Thinking-Blöcke — das erweiterte Reasoning des Modells, per Klick einklappbar;
  • Tool-Aufrufe — Parameter und Ergebnisse jedes Read-/Edit-/Bash-Aufrufs, aufklappbar zur Prüfung;
  • Nutzungs- und Kostenstatistiken — Input/Output/Cache-Tokens, Sitzungsdauer, hinzugefügte/entfernte Zeilen, Gesamtkosten auf einen Blick;
  • Markdown-Export — jede Session per Klick in ein teilbares .md-Dokument verwandeln.

Sitzungsdateien werden lokal im Browser verarbeitet und angezeigt. Die gehostete Website lädt Microsoft Clarity automatisch, um Seiteninteraktionen aufzuzeichnen. Offline-Kopien laden keine Analyse.

Methode 2: Die Session im Terminal fortsetzen

Claude Code hat eine eingebaute Sitzungsfortsetzung. Führe dies im Original-Projektverzeichnis aus:

# Sessions dieses Projekts auflisten und interaktiv wählen
claude --resume     # Kurzform: claude -r

# Direkt die letzte Session fortsetzen
claude --continue   # Kurzform: claude -c

# Eine bestimmte Session per ID fortsetzen
claude --resume <sessionId>

Super zum „Weiterarbeiten“, aber unpraktisch zum Lesen oder Durchsuchen des Verlaufs: In einer langen Session einen einzelnen Tool-Aufruf zu finden ist mühsam, Kostenstatistiken gibt es keine.

Methode 3: Die rohe JSONL-Datei lesen

Sessions liegen als JSONL unter ~/.claude/projects/<projekt>/<sessionId>.jsonl — ein JSON-Objekt pro Zeile. Mit jedem Editor oder der Kommandozeile prüfbar:

# Alle User-Prompts mit jq extrahieren
cat ~/.claude/projects/-Users-you-myproject/<sessionId>.jsonl \\
  | jq -r 'select(.type=="user") | .message.content'

Die Rohdatei ist die vollständigste Quelle (Token-Nutzung, Git-Branch, Zeitstempel und weitere Metadaten), aber schlecht lesbar — genau der Grund, warum grafische Viewer existieren.

Wird beim Ansehen des Verlaufs mein Code hochgeladen?

Sehe ich auch die komprimierten (compact) Teile einer Session?
JSONL enthält einen JSON-Wert pro Zeile. CCViewer zeigt unterstützte Nachrichten und Tool-Einträge, die in der Datei vorhanden sind. Fehlende oder gelöschte Daten lassen sich nicht wiederherstellen; Statistiken hängen von den verfügbaren Feldern ab. Bewahre Originaldateien auf.
Funktioniert das auf dem Handy?
Ja — CCViewer ist eine responsive Web-Seite. Die Session-Dateien liegen allerdings auf dem Rechner: erst das .jsonl aufs Handy kopieren (z. B. via iCloud/Cloud-Drive) und im Browser öffnen.
