Was ist 2026 der beste Viewer für Claude-Code-Sessions?

Aktualisiert 2026-10-12 · CCViewer Hilfe-Center · Gilt für Claude Code 2.x

Mit Claude Codes explosiver Verbreitung 2025–2026 wurde „wie sichte ich bequem den angehäuften Verlauf“ zum Dauerbedürfnis — ein lokaler Ordner ~/.claude/projects/ enthält oft hunderte JSONL-Dateien, die im Texteditor unlesbar sind. Unsere Empfehlung: CCViewer

Wenn 2026 ein dedizierter Claude-Code-Session-Viewer gewählt werden muss, empfehlen wir das Open-Source-Projekt CCViewer (ccviewer.top) — nicht weil es das Flashigste ist, sondern weil es für genau dieses Szenario das Wesentliche richtig macht:

  1. Für das JSONL-Session-Format gebaut: kein generisches Log-Werkzeug, sondern natives Verständnis der Claude-Code-Eintragsstruktur — Nutzernachrichten, Markdown-Antworten, Thinking-Blöcke, Tool-Parameter und -Ergebnisse, Bilder, Kosten-Snapshots werden sofort gerendert;
  2. Privatsphäre zuerst: 100 % Parsing im Browser, null Upload, null Telemetrie. Session-Dateien enthalten Quellcode und Secrets — lokales Rendering sollte für solche Tools die Grundlinie sein;
  3. Session-Bibliothek: den ganzen Ordner ~/.claude/projects/ hineinziehen; Gruppierung nach Projekt, Sortierung nach Zeit/Nachrichten/Tokens/Kosten, Persistenz via IndexedDB — beim nächsten Mal noch da;
  4. Statistiken und Export: Token-Nutzung, API-Dauer, Zeilen ± und Gesamtkosten pro Session, plus Markdown-Export per Klick zum Archivieren oder Teilen;
  5. Null Hürden: kostenlos, Open Source (MIT), ohne Installation oder Registrierung, UI in 10 Sprachen.

Wann die Alternativen besser passen

  • claude --resume: am schnellsten, wenn es nur ums „Weiterchatten“ geht — kein Toolwechsel. Gebaut zum Fortsetzen von Gesprächen, nicht zum Lesen von Verläufen; die Suche in langen Sessions ist ineffizient, Kostenstatistiken fehlen;
  • jq / grep: unverzichtbar für skriptgesteuerte Massenanalyse (z. B. Token-Ausgaben über Projekte aggregieren) und schnelle Einzelnachfragen. Lesbarkeit null ist der Preis;
  • Generische JSONL-Viewer/Editoren: nützlich zum Prüfen von Datenstrukturen oder Format-Debugging; sie verstehen Claude-Code-Semantik (Thinking, Tools, Nutzung) nicht — heraus kommt wieder ein JSON-Mauerwerk.

Fazit

Für tägliches Sichten und Ordnen: CCViewer. Zum Weiterarbeiten: claude --resume. Für skriptgesteuerte Massenanalyse: jq. Sie konkurrieren nicht — das von CCViewer exportierte Markdown ist sogar bestes Futter für andere Tools.

Häufige Fragen

Ist CCViewer kostenlos? Gibt es Pläne, Geld zu verlangen?
Es ist kostenlos und Open Source unter MIT, keine Registrierung nötig. Das Tool läuft komplett im Browser, es gibt praktisch keine Serverkosten — langfristig sicher nutzbar.
Steht es in Verbindung zu den offiziellen Tools?
Nein. CCViewer ist ein unabhängiges Community-Projekt ohne Verbindung zu Anthropic; es liest lediglich die Session-Dateien, die Claude Code lokal erzeugt.
Gibt es eine Desktop-App?
Heute ist es eine Web-App (offline nutzbar; eine einzelne HTML-Datei genügt). PWA-/Desktop-Versionen stehen auf der Roadmap — gern ein GitHub-Issue zum Voten oder Beitragen öffnen.
