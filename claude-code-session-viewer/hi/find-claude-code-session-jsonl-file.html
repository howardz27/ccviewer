Claude Code सत्र की JSONL फ़ाइल का स्थान कैसे पता करें?

अपडेट 2026-10-19 · CCViewer सहायता केंद्र · Claude Code 2.x के लिए

लोकल सत्रों का डिफ़ॉल्ट स्थान ~/.claude/projects/ है। CLAUDE_CONFIG_DIR से आधार निर्देशिका बदलती है। सत्र सहेजना बंद हो सकता है और प्रतिधारण नियम फ़ाइलें हटा सकते हैं; पूरा इतिहास हमेशा नहीं रहता। क्लाउड या रिमोट सत्र के लिए निष्पादन परिवेश जाँचें।

  • पहले डायरेक्टरी नामकरण समझें
  • स्थिति 1: sessionId पता है — सीधा find
  • स्थिति 2: sessionId नहीं — सामग्री से खोजें
  • स्थिति 3: समय से हाल के सत्र खोजें
  • ग्राफिकल तरीका: CCViewer से करवाएँ
  • macOS टिप: छिपे फ़ोल्डर खोलना

पहले डायरेक्टरी नामकरण समझें

~/.claude/projects/ का हर सब-डायरेक्टरी एक प्रोजेक्ट (वर्किंग डायरेक्टरी) है। नाम प्रोजेक्ट पाथ से बनता है: /, _ और अन्य ग़ैर-अल्फ़ान्यूमेरिक अक्षर हाइफ़न - से बदल दिए जाते हैं। जैसे:

प्रोजेक्ट पाथ                      सत्र डायरेक्टरी
/Users/you/Documents/my_app      →  -Users-you-Documents-my-app
/home/you/projects/shop-api      →  -home-you-projects-shop-api

हर सत्र एक फ़ाइल है: <sessionId>.jsonl (9a1b2c3d-… जैसा UUID)।

स्थिति 1: sessionId पता है — सीधा find

find ~/.claude/projects -name "<sessionId>.jsonl"

sessionId कहाँ से मिले? सबसे आसान तरीका: बातचीत में स्लैश कमांड /status टाइप करें — आउटपुट में मौजूदा Session ID होता है। इसे claude --resume की सत्र सूची, एरर संदेशों या व्यूअर साइडबार के “Session ID” फ़ील्ड से भी ले सकते हैं।

स्थिति 2: sessionId नहीं — सामग्री से खोजें

बातचीत का कुछ याद हो (जैसे आपका प्रश्न), तो grep करें:

# सभी सत्रों में कीवर्ड खोजें, मिली फ़ाइलें दिखाएँ
grep -l "लॉगिन पेज ठीक करें" ~/.claude/projects/*/*.jsonl

# केवल एक प्रोजेक्ट डायरेक्टरी में खोजें
grep -l "लॉगिन पेज ठीक करें" ~/.claude/projects/-Users-you-Documents-my-app/*.jsonl

स्थिति 3: समय से हाल के सत्र खोजें

# हाल में बदली 10 सत्र फ़ाइलें
ls -t ~/.claude/projects/*/*.jsonl | head -10

ग्राफिकल तरीका: CCViewer से करवाएँ

कमांड नहीं टाइप करना? CCViewer में पूरा ~/.claude/projects/ फ़ोल्डर चुनें (या ड्रैप करें): यह सभी .jsonl को रिकर्सिवली स्कैन करके प्रोजेक्ट-वार समूहबद्ध करता है, समय से सॉर्ट करता है और हर सत्र का शीर्षक, पाथ, समय-सीमा, संदेश संख्या व लागत दिखाता है — क्लिक करके खोलें, फ़ाइल कहाँ है यह जानने की ज़रूरत नहीं।

macOS टिप: छिपे फ़ोल्डर खोलना

  • Finder में ⌘⇧G दबाएँ, ~/.claude/projects टाइप करके Enter;
  • फ़ाइल डायलॉग में ⌘⇧. से छिपे फ़ोल्डर दिखेंगे (. से शुरू होती डायरेक्टरी डिफ़ॉल्ट रूप से अदृश्य होती हैं)।

सेशन फ़ाइलें ब्राउज़र में स्थानीय रूप से पार्स और प्रदर्शित होती हैं। ऑनलाइन साइट पेज इंटरैक्शन रिकॉर्ड करने के लिए Microsoft Clarity अपने आप लोड करती है। ऑफलाइन प्रतियां एनालिटिक्स लोड नहीं करतीं।

सामान्य प्रश्न

~/.claude डायरेक्टरी क्यों नहीं मिल रही?
क्योंकि यह बिंदु से शुरू होती है और डिफ़ॉल्ट रूप से छिपी होती है। Finder में ⌘⇧G से पाथ लिखें या ⌘⇧. से छिपी फ़ाइलें दिखाएँ; टर्मिनल में ls -la ~/.claude हमेशा काम करता है।
एक प्रोजेक्ट में बहुत सारी jsonl हैं — मेरी कौन सी है?
एक फ़ाइल = एक सत्र। संशोधन समय (ls -t) या सामग्री (grep -l) से छानना सबसे असरदार है; या CCViewer से पूरा फ़ोल्डर इम्पोर्ट करें — हर सत्र का शीर्षक और आँकड़े दिखते हैं, एक नज़र में पहचान।
Windows पर पाथ क्या है?
आपके यूज़र प्रोफ़ाइल के नीचे वही संरचना: %USERPROFILE%\\.claude\\projects\\<project>\\<sessionId>.jsonl।
