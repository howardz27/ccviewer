Claude Code सत्र की जानकारी कहाँ संग्रहित होती है?

अपडेट 2026-10-12 · CCViewer सहायता केंद्र · Claude Code 2.x के लिए

संक्षिप्त उत्तर: सब कुछ लोकल रूप से ~/.claude/projects/ के अंतर्गत JSONL फ़ाइलों में सेव होता है — न क्लाउड सिंक, न खाते से जुड़ा सत्र इतिहास।

डायरेक्टरी संरचना

~/.claude/
├── projects/                     # ← पूरा सत्र इतिहास यहीं है
│   ├── -Users-you-Documents-app/ #   हर प्रोजेक्ट की एक डायरेक्टरी (पाथ बदला हुआ)
│   │   ├── 9a1b2c3d-….jsonl     #     हर सत्र की एक फ़ाइल
│   │   └── 7c2d3e4f-….jsonl
│   └── -home-you-shop-api/
│       └── …
├── claude.json                   # ग्लोबल कॉन्फ़िग (MCP, थीम, प्रोजेक्ट स्थिति)
└── … (कैश, लॉग, आँकड़े व अन्य सहायक फ़ाइलें)

प्रोजेक्ट डायरेक्टरी के नाम का नियम: पाथ का हर ग़ैर-अल्फ़ान्यूमेरिक अक्षर (/, _, …) - बन जाता है। इसलिए एक प्रोजेक्ट के सारे सत्र एक ही डायरेक्टरी में रहते हैं — व्यूअरों का “प्रोजेक्ट-वार समूह” भी इसी पर आधारित है।

JSONL फ़ाइल में क्या होता है

JSONL = हर लाइन में एक स्वतंत्र JSON ऑब्जेक्ट। सत्र फ़ाइल पूरी बातचीत को कालक्रम में रिकॉर्ड करती है। मुख्य प्रविष्टि प्रकार:

typeसामग्री
userआपका इनपुट (टेक्स्ट / चित्र) और वापस भेजे गए टूल परिणाम
assistantमॉडल उत्तर: टेक्स्ट, थिंकिंग ब्लॉक, tool_use कॉल और टोकन उपयोग
systemसिस्टम घटनाएँ (hooks आदि)
summary / ai-titleसत्र सारांश और स्वतः बना शीर्षक
cost-stateलागत व उपयोग स्नैपशॉट (कुल लागत, ±लाइनें, API अवधि)

हर प्रविष्टि में मेटाडेटा भी होता है: timestamp, cwd (प्रोजेक्ट पाथ), gitBranch, version, sessionId आदि। यानी इतिहास फ़ाइल टर्मिनल की तुलना में अधिक पूर्ण है — रीज़निंग, टूल कॉल के रॉ पैरामीटर व परिणाम और टोकन खपत सब अंदर है।

इसका मतलब

  • प्राइवेसी आपके हाथ में: फ़ाइलें कभी आपकी मशीन से बाहर नहीं जातीं। इसके बदले, मशीन बदलने/री-इंस्टॉल से पहले ~/.claude/projects/ का बैकअप लें, वरना इतिहास चला जाएगा;
  • फ़ाइलें संवेदनशील हो सकती हैं: सत्रों में सोर्स कोड अंश, फ़ाइल पाथ, कमांड आउटपुट, कभी-कभी सीक्रेट्स — .jsonl फ़ाइलें बेतरतीब शेयर या पब्लिकली अपलोड न करें;
  • साइज़ बढ़ता है: महीनों के भारी उपयोग के बाद एक सत्र कई (या दर्जनों) MB और पूरी डायरेक्टरी सैकड़ों MB — यह सामान्य है।

यह इतिहास आराम से कैसे पढ़ें

रॉ JSONL पढ़ना थकाऊ है। CCViewer से डायरेक्टरी खोलें (पूरा फ़ोल्डर ड्रैप करना भी चलता है): सत्र प्रोजेक्ट-वार समूहबद्ध होंगे और Markdown, थिंकिंग ब्लॉक, टूल कॉल, लागत आँकड़े सब ग्राफिकली रेंडर होंगे — पार्सिंग केवल आपके ब्राउज़र में होती है, “डेटा इस मशीन से बाहर नहीं जाता” बना रहता है।

CCViewer से अपने Claude Code सत्र विज़ुअली रीप्ले करें
पेज खोलें और कोई .jsonl फ़ाइल — या पूरा ~/.claude/projects/ फ़ोल्डर — ड्रैप कर दें। Markdown रेंडरिंग, थिंकिंग ब्लॉक, टूल कॉल, टोकन व लागत आँकड़े सब आपके ब्राउज़र में लोकल चलते हैं, कुछ भी अपलोड नहीं होता।

सामान्य प्रश्न

Claude Code का इतिहास Anthropic के सर्वर पर अपलोड होता है?
सत्र फ़ाइलें लोकल ~/.claude/projects/ में रहती हैं और अलग से क्लाउड पर संग्रहित नहीं होतीं। बेशक बातचीत के दौरान सामग्री API से प्रोसेस होती है (मॉडल उपयोग की शर्त), लेकिन “इतिहास फ़ाइलें” लोकल फ़ाइलें हैं जिन पर आपका पूरा नियंत्रण है।
सत्र इतिहास कैसे मिटाएँ?
संबंधित .jsonl फ़ाइल (या प्रोजेक्ट की पूरी सब-डायरेक्टरी) हटा दें; सत्र resume सूची से भी गायब हो जाएगा। हटाने से पहले बैकअप की ज़रूरत न हो, यह पक्का करें।
क्या ~/.claude/projects और ~/.claude.json एक ही चीज़ हैं?
नहीं। ~/.claude.json (या claude.json) ग्लोबल कॉन्फ़िग फ़ाइल है (MCP सर्वर, थीम आदि); सत्र इतिहास ~/.claude/projects/ के .jsonl फ़ाइलों में रहता है।
