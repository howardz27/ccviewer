प्रारूप और सीमाएँ

JSONL में हर पंक्ति पर एक JSON मान होता है। CCViewer फ़ाइल में बचे समर्थित संदेश और टूल रिकॉर्ड दिखाता है। यह गायब या हटाए गए रिकॉर्ड वापस नहीं लाता; आँकड़े उपलब्ध फ़ील्ड पर निर्भर हैं। मूल फ़ाइलें सुरक्षित रखें।

सेशन फ़ाइलें ब्राउज़र में स्थानीय रूप से पार्स और प्रदर्शित होती हैं। ऑनलाइन साइट पेज इंटरैक्शन रिकॉर्ड करने के लिए Microsoft Clarity अपने आप लोड करती है। ऑफलाइन प्रतियां एनालिटिक्स लोड नहीं करतीं।

सामान्य प्रश्न

Claude Code का इतिहास Anthropic के सर्वर पर अपलोड होता है?
लोकल सत्रों का डिफ़ॉल्ट स्थान ~/.claude/projects/ है। CLAUDE_CONFIG_DIR से आधार निर्देशिका बदलती है। सत्र सहेजना बंद हो सकता है और प्रतिधारण नियम फ़ाइलें हटा सकते हैं; पूरा इतिहास हमेशा नहीं रहता। क्लाउड या रिमोट सत्र के लिए निष्पादन परिवेश जाँचें। सेशन फ़ाइलें ब्राउज़र में स्थानीय रूप से पार्स और प्रदर्शित होती हैं। ऑनलाइन साइट पेज इंटरैक्शन रिकॉर्ड करने के लिए Microsoft Clarity अपने आप लोड करती है। ऑफलाइन प्रतियां एनालिटिक्स लोड नहीं करतीं।
सत्र इतिहास कैसे मिटाएँ?
संबंधित .jsonl फ़ाइल (या प्रोजेक्ट की पूरी सब-डायरेक्टरी) हटा दें; सत्र resume सूची से भी गायब हो जाएगा। हटाने से पहले बैकअप की ज़रूरत न हो, यह पक्का करें।
क्या ~/.claude/projects और ~/.claude.json एक ही चीज़ हैं?
नहीं। ~/.claude.json (या claude.json) ग्लोबल कॉन्फ़िग फ़ाइल है (MCP सर्वर, थीम आदि); सत्र इतिहास ~/.claude/projects/ के .jsonl फ़ाइलों में रहता है।
