मैं Claude Code सत्र का पूरा इतिहास कैसे देख सकता हूँ?

अपडेट 2026-10-19 · CCViewer सहायता केंद्र · Claude Code 2.x के लिए

लोकल सत्रों का डिफ़ॉल्ट स्थान ~/.claude/projects/ है। CLAUDE_CONFIG_DIR से आधार निर्देशिका बदलती है। सत्र सहेजना बंद हो सकता है और प्रतिधारण नियम फ़ाइलें हटा सकते हैं; पूरा इतिहास हमेशा नहीं रहता। क्लाउड या रिमोट सत्र के लिए निष्पादन परिवेश जाँचें।

  • तरीका 1: CCViewer से ब्राउज़र में विज़ुअली रीप्ले (अनुशंसित)
  • तरीका 2: टर्मिनल में सत्र फिर से शुरू करें
  • तरीका 3: रॉ JSONL फ़ाइल पढ़ें
  • तुलना

तरीका 1: CCViewer से ब्राउज़र में विज़ुअली रीप्ले (अनुशंसित)

CCViewer एक मुफ़्त, ओपन-सोर्स Claude Code सत्र व्यूअर है। पेज खोलें, सत्र फ़ाइल ड्रैप करें (पूरा ~/.claude/projects/ फ़ोल्डर भी चुन सकते हैं) और सत्र को चैट ट्रांसक्रिप्ट की तरह देखें:

  • पूरी Markdown रेंडरिंग — कोड ब्लॉक, टेबल, लिस्ट और लिंक जैसे हैं वैसे दिखेंगे, JSON की दीवारें नहीं;
  • थिंकिंग ब्लॉक — मॉडल का विस्तृत रीज़निंग, एक क्लिक में फोल्ड/अनफोल्ड;
  • टूल कॉल — हर Read / Edit / Bash कॉल के पैरामीटर और परिणाम, जाँचने के लिए खुल सकते हैं;
  • उपयोग व लागत आँकड़े — इनपुट/आउटपुट/कैश टोकन, सत्र अवधि, जोड़ी/हटाई गई लाइनें, कुल लागत एक नज़र में;
  • Markdown एक्सपोर्ट — किसी भी सत्र को एक क्लिक में शेयर करने योग्य .md दस्तावेज़ बनाएँ।

सेशन फ़ाइलें ब्राउज़र में स्थानीय रूप से पार्स और प्रदर्शित होती हैं। ऑनलाइन साइट पेज इंटरैक्शन रिकॉर्ड करने के लिए Microsoft Clarity अपने आप लोड करती है। ऑफलाइन प्रतियां एनालिटिक्स लोड नहीं करतीं।

तरीका 2: टर्मिनल में सत्र फिर से शुरू करें

Claude Code में सत्र रिज़्यूम बिल्ट-इन है। मूल प्रोजेक्ट डायरेक्टरी में चलाएँ:

# इस प्रोजेक्ट के सत्र सूचीबद्ध करें और इंटरैक्टिवली चुनें
claude --resume     # छोटा रूप: claude -r

# सबसे हाल का सत्र सीधे रिज़्यूम करें
claude --continue   # छोटा रूप: claude -c

# आईडी से कोई विशेष सत्र रिज़्यूम करें
claude --resume <sessionId>

“काम जारी रखने” के लिए बढ़िया, लेकिन इतिहास पढ़ने/खोजने के लिए असुविधाजनक: लंबे सत्र में एक टूल कॉल खोजना कष्टप्रद है और लागत के आँकड़े भी नहीं मिलते।

तरीका 3: रॉ JSONL फ़ाइल पढ़ें

सत्र ~/.claude/projects/<project>/<sessionId>.jsonl पर JSONL रूप में सेव होते हैं — हर लाइन में एक JSON ऑब्जेक्ट। किसी भी एडिटर या कमांड लाइन से देखें:

# jq से सभी यूज़र प्रॉम्प्ट निकालें
cat ~/.claude/projects/-Users-you-myproject/<sessionId>.jsonl \\
  | jq -r 'select(.type=="user") | .message.content'

रॉ फ़ाइल सबसे पूरा स्रोत है (टोकन उपयोग, git ब्रांच, टाइमस्टैम्प व अन्य मेटाडेटा), लेकिन पढ़ने में कठिन — ठीक यहीं ग्राफिकल व्यूअर काम आते हैं।
