Claude Code session 的历史信息保存在哪里？

更新于 2026-10-12 · CCViewer 帮助中心 · 适用于 Claude Code 2.x

简短回答：全部保存在你电脑本地的 ~/.claude/projects/ 目录下，以 JSONL 文件形式存在，不上传云端。没有账号系统，也没有云端会话历史。

目录结构

~/.claude/
├── projects/                     # ← 所有会话历史都在这里
│   ├── -Users-you-Documents-app/ #   每个项目一个目录（路径转义而来）
│   │   ├── 9a1b2c3d-….jsonl     #     每次会话一个文件
│   │   └── 7c2d3e4f-….jsonl
│   └── -home-you-shop-api/
│       └── …
├── claude.json                   # 全局配置（MCP、主题、项目级状态）
└── …（缓存、日志、统计等辅助文件）

项目目录名的规则：项目路径中的 /、_ 等非字母数字字符被替换成 -。所以同一个项目的所有会话都聚在同一个目录下 —— 这也是各类查看器「按项目分组」的依据。

JSONL 文件里有什么

JSONL = 每行一个独立的 JSON 对象。一个会话文件按时间顺序记录了完整对话过程，主要条目类型：

type内容
user你的输入（文本 / 图片），以及工具执行结果回传
assistant模型回复：正文、思考块（thinking）、工具调用（tool_use）及 token 用量
system系统事件（hooks 等）
summary / ai-title会话摘要与自动生成的标题
cost-state费用与用量快照（总费用、代码行数增减、API 耗时）

每个条目还带有元数据：timestamp（时间戳）、cwd（项目路径）、gitBranch、version、sessionId 等。也就是说，历史文件比终端显示的更完整 —— 思考过程、每次工具调用的原始参数与结果、token 消耗都在里面。

这意味着什么

  • 隐私在你手里：文件只在本机。相应地，换电脑/重装系统前记得备份 ~/.claude/projects/，否则历史会全部丢失；
  • 文件可能很敏感：会话记录包含你的源码片段、文件路径、命令输出，甚至密钥 —— 不要随手把 .jsonl 发给别人或上传到公开位置；
  • 体积会增长：重度使用几个月后单个会话可达数 MB 甚至几十 MB，整目录几百 MB 很常见，属正常现象。

常见问题

Claude Code 的历史会上传到 Anthropic 服务器吗？
会话文件本身保存在本地 ~/.claude/projects/，不会单独上传存储。当然，对话发生时内容会经由 API 处理（这是使用模型的前提），但「历史记录文件」是本地文件，你拥有完全控制权。
删除会话历史怎么做？
直接删除对应的 .jsonl 文件（或整个项目子目录）即可，Claude Code 的恢复列表里也就不会再出现。删除前建议确认不需要备份。
~/.claude/projects 和 ~/.claude.json 是一回事吗？
不是。~/.claude.json（或 claude.json）是全局配置文件，存 MCP 服务器、主题等设置；会话历史在 ~/.claude/projects/ 目录下的 .jsonl 文件里。
