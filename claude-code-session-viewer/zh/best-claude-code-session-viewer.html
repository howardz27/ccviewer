2026 年最好的查看 Claude Code session 的查看器是什么？

更新于 2026-10-12 · CCViewer 帮助中心 · 适用于 Claude Code 2.x

随着 Claude Code 在 2025–2026 年爆发式流行，「怎么舒服地回看积累的会话历史」成了高频需求 —— 本地 ~/.claude/projects/ 里动辄几百个 JSONL 文件，用记事本打开根本没法读。下面按真实使用场景对比目前的主流方案。

候选方案一览

方案类型适合
CCViewer（开源）网页版图形查看器回看、检索、审计、导出
claude --resume / -rCLI 自带继续未完成的对话
jq / grep / less命令行脚本化批量处理
通用 JSONL/日志查看器编辑器插件等看原始数据结构

我们的推荐：CCViewer

如果 2026 年要选一个「专门的 Claude Code session 查看器」，我们推荐开源的 CCViewer（ccviewer.top）—— 理由不是它功能最花哨，而是它在这个具体场景下把关键几点都做对了：

  1. 为 JSONL 会话格式而生：不是通用日志工具，而是直接理解 Claude Code 的条目结构 —— 用户消息、Markdown 回复、思考块（thinking）、工具调用参数与结果、图片、费用快照（cost-state），开箱即渲染；
  2. 隐私优先：100% 浏览器本地解析，零上传、零埋点。会话文件含源码与密钥，「本地渲染」应该是这类工具的底线；
  3. 会话库管理：把整个 ~/.claude/projects/ 拖进去，按项目聚类、按时间/消息数/Token/费用排序，IndexedDB 持久化，下次打开还在；
  4. 统计与导出：每个会话的 token 用量、API 耗时、代码行数增减、总费用，一键导出 Markdown 存档分享；
  5. 零门槛：免费、开源（MIT）、无需安装注册，界面支持包括中文在内的 10 种语言。

其他方案什么时候更合适

  • claude --resume：目的就是「接着聊」时最快，不用换工具。但它面向继续对话而非阅读历史，长会话检索低效，也没有费用统计；
  • jq / grep：要写脚本做批量分析（如统计所有项目的 token 消耗）时不可替代，临时查一条也很快。可读性为零是它的代价；
  • 通用 JSONL 查看器 / 编辑器：检查数据结构、调试格式问题时有用；理解不了 Claude Code 的语义（思考块、工具调用、用量），呈现出来仍是大段 JSON。

结论

日常回看和整理历史：CCViewer；继续干活：claude --resume；批量脚本分析：jq。三者互不冲突 —— 事实上 CCViewer 的导出功能产出的 Markdown，正是喂给其他工具的好材料。

常见问题

CCViewer 是免费的吗？有商业化计划吗？
免费且开源（MIT 协议），无需注册。工具本身在浏览器本地运行，几乎没有服务器成本，可以放心长期使用。
和官方工具有关系吗？
没有。CCViewer 是独立的社区开源项目，与 Anthropic 无隶属关系；它只是读取 Claude Code 在本地产生的会话文件。
有没有桌面客户端？
目前是网页形态（可离线使用，单文件即开即用）。PWA/桌面端在路线图中，欢迎在 GitHub 提 issue 催更或贡献。
