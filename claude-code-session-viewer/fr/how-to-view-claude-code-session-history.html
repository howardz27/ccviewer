Comment voir l’historique complet d’une session Claude Code ?

Mis à jour 2026-10-12 · CCViewer Centre d'aide · Concerne Claude Code 2.x

Claude Code enregistre chaque session intégralement sur votre disque local. Il existe donc trois grandes façons de consulter l’historique, classées ici par facilité d’utilisation.

Méthode 1 : la rejouer visuellement dans le navigateur avec CCViewer (recommandé)

CCViewer est un visualiseur de sessions Claude Code gratuit et open source. Ouvrez la page, déposez un fichier de session (vous pouvez aussi importer tout le dossier ~/.claude/projects/) et rejouez la session comme une conversation :

  • Rendu Markdown complet — blocs de code, tableaux, listes et liens affichés tel quel, fini les murs de JSON ;
  • Blocs de réflexion — le raisonnement étendu du modèle, repliable en un clic ;
  • Appels d’outils — paramètres et résultats de chaque appel Read / Edit / Bash, dépliables pour inspection ;
  • Statistiques d’usage et de coût — tokens entrée/sortie/cache, durée de session, lignes ajoutées/supprimées, coût total en un coup d’œil ;
  • Export Markdown — transformez n’importe quelle session en document .md partageable en un clic.

Point crucial : l’analyse et le rendu se font à 100 % dans votre navigateur — rien n’est téléversé. Cela compte : les fichiers de session contiennent votre code source, des chemins de fichiers et parfois des secrets.

Méthode 2 : reprendre la session dans le terminal

Claude Code intègre la reprise de session. Exécutez ceci dans le répertoire d’origine du projet :

# Lister les sessions du projet et en choisir une interactivement
claude --resume     # raccourci : claude -r

# Reprendre directement la session la plus récente
claude --continue   # raccourci : claude -c

# Reprendre une session précise par ID
claude --resume <sessionId>

Parfait pour « continuer à travailler », mais peu pratique pour lire ou chercher dans l’historique : dépiler une longue session pour retrouver un appel d’outil est pénible, et il n’y a aucune statistique de coût.

Méthode 3 : lire le fichier JSONL brut

Les sessions sont stockées en JSONL dans ~/.claude/projects/<projet>/<sessionId>.jsonl — un objet JSON par ligne. Vous pouvez les inspecter avec n’importe quel éditeur ou en ligne de commande :

# Extraire tous les prompts utilisateur avec jq
cat ~/.claude/projects/-Users-you-myproject/<sessionId>.jsonl \\
  | jq -r 'select(.type=="user") | .message.content'

Le fichier brut est la source la plus complète (usage des tokens, branche git, horodatages et autres métadonnées), mais sa lisibilité est mauvaise — c’est exactement pour cela que les visualiseurs graphiques existent.

FAQ

Consulter l’historique téléverse-t-il mon code ?
Non. CCViewer analyse et affiche tout dans votre navigateur ; aucune requête réseau ne transporte le contenu des sessions. Vous pouvez le vérifier vous-même dans le panneau Network des DevTools.
Peut-on voir les parties compactées d’une session ?
Oui. Les résumés de compactage et les messages suivants vivent dans le même fichier JSONL ; le visualiseur affiche les résumés comme contexte injecté, visible via l’interrupteur « Système/Injecté ».
Cela fonctionne-t-il sur mobile ?
Oui — CCViewer est une page web responsive. Mais les fichiers de session sont sur votre ordinateur : copiez d’abord le .jsonl sur le téléphone (via iCloud/drive par ex.) puis ouvrez-le dans un navigateur.
