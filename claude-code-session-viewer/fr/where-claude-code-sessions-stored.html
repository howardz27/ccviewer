Où sont stockées les informations d’historique des sessions Claude Code ?

Mis à jour 2026-10-19 · CCViewer Centre d'aide · Concerne Claude Code 2.x

Les sessions locales sont enregistrées par défaut sous ~/.claude/projects/. CLAUDE_CONFIG_DIR change le répertoire de base. La persistance peut être désactivée et la rétention peut supprimer des fichiers : tout ne reste pas nécessairement disponible. Vérifiez où les sessions distantes ou cloud ont été exécutées.

Emplacement et rétention

  • ~/.claude/projects/<project>/<session-id>.jsonl — JSONL
  • ~/.claude/settings.json — settings
  • ~/.claude.json — configuration

Claude Code — Emplacement et rétention

Format et limites

JSONL contient une valeur JSON par ligne. CCViewer affiche les messages et appels d’outils pris en charge qui restent dans le fichier. Il ne restaure pas les données absentes ou supprimées ; les statistiques dépendent des champs disponibles. Conservez les originaux.

Les fichiers de session sont analysés et affichés localement dans le navigateur. Le site hébergé charge automatiquement Microsoft Clarity pour enregistrer les interactions. Les copies hors ligne ne chargent pas de mesure.

FAQ

L’historique de Claude Code est-il téléversé sur les serveurs d’Anthropic ?
Les sessions locales sont enregistrées par défaut sous ~/.claude/projects/. CLAUDE_CONFIG_DIR change le répertoire de base. Comment supprimer l’historique des sessions ?
Supprimez simplement le fichier .jsonl correspondant (ou tout le sous-répertoire du projet) ; la session disparaît alors de la liste de reprise. Vérifiez d’abord que vous n’avez pas besoin d’une sauvegarde.
~/.claude/projects et ~/.claude.json, est-ce la même chose ?
Non. ~/.claude.json (ou claude.json) est le fichier de configuration globale (serveurs MCP, thème, etc.) ; l’historique des sessions vit dans les fichiers .jsonl sous ~/.claude/projects/.
