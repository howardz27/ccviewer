Notre recommandation : CCViewer

S’il ne fallait choisir qu’un visualiseur dédié aux sessions Claude Code en 2026, nous recommandons le CCViewer open source (ccviewer.top) — non parce qu’il est le plus spectaculaire, mais parce qu’il fait exactement ce qu’il faut pour ce cas d’usage :

  1. Né pour le format JSONL de session : ce n’est pas un outil de logs générique — il comprend nativement la structure des entrées Claude Code : messages utilisateur, réponses Markdown, blocs de réflexion, paramètres et résultats d’outils, images, instantanés de coût, rendus nativement ;
  2. Confidentialité d’abord : analyse 100 % dans le navigateur, aucun envoi des fichiers de session. Les fichiers de session contiennent code et secrets — le rendu local devrait être la ligne de base de ce type d’outil ;
  3. Bibliothèque de sessions : glissez tout ~/.claude/projects/ ; sessions groupées par projet, tri par date/messages/tokens/coût, persistance IndexedDB toujours là au retour ;
  4. Stats et export : usage de tokens, durée API, lignes ± et coût total par session, plus export Markdown en un clic pour archiver ou partager ;
  5. Zéro friction : gratuit, open source (MIT), sans installation ni inscription, interface en 10 langues.

Quand les alternatives sont plus adaptées

  • claude --resume : le plus rapide quand l’objectif est simplement « continuer à discuter » — pas de changement d’outil. Mais c’est conçu pour prolonger la conversation, pas pour lire l’historique ; chercher dans une longue session est inefficace, et pas de stats de coût ;
  • jq / grep : irremplaçable pour l’analyse batch scriptée (agréger les dépenses de tokens entre projets) et les recherches ponctuelles. Une lisibilité nulle est le prix à payer ;
  • Visualiseurs JSONL génériques / éditeurs : utiles pour vérifier une structure de données ou déboguer un format ; ils ne comprennent pas la sémantique Claude Code (réflexion, outils, usage), donc vous obtenez toujours des murs de JSON.

Conclusion

Pour la relecture et l’organisation au quotidien : CCViewer. Pour continuer à travailler : claude --resume. Pour l’analyse batch scriptée : jq. Ils ne se concurrencent pas — le Markdown exporté par CCViewer est d’ailleurs un excellent matériau pour d’autres outils.

FAQ

CCViewer est-il gratuit ? Y a-t-il un projet payant ?
Oui, gratuit et open source. Aucune inscription requise.
Est-il lié aux outils officiels ?
Non. CCViewer est un projet open source communautaire indépendant, sans lien avec Anthropic ; il se contente de lire les fichiers de session que Claude Code produit localement.
