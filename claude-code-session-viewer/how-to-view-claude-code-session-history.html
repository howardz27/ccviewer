How do I view the full history of a Claude Code session?

Updated 2026-10-12 · CCViewer Help Center · Applies to Claude Code 2.x

Claude Code records every session completely on your local disk, so there are three main ways to view the history — ranked by ease of use below.

Method 1: Replay it visually in the browser with CCViewer (recommended)

CCViewer is a free, open-source Claude Code session viewer. Open the page, drop in a session file (you can also pick the whole ~/.claude/projects/ folder to import everything), and replay the session like a chat transcript:

  • Full Markdown rendering — code blocks, tables, lists and links rendered as-is, no more walls of JSON;
  • Thinking blocks — the model’s extended reasoning, collapsible with one click;
  • Tool calls — parameters and results of every Read / Edit / Bash call, expandable for inspection;
  • Usage & cost stats — input/output/cache tokens, session duration, lines added/removed, total cost at a glance;
  • Markdown export — turn any session into a shareable .md document in one click.

Crucially, it parses and renders 100% locally in your browser — nothing is uploaded. That matters: session files contain your source code, file paths and sometimes secrets.

Method 2: Resume the session in the terminal

Claude Code has built-in session resume. Run this in the original project directory:

# List this project's sessions and pick one interactively
claude --resume     # shorthand: claude -r

# Resume the most recent session directly
claude --continue   # shorthand: claude -c

# Resume a specific session by ID
claude --resume <sessionId>

Great for "keep working", but inconvenient for reading or searching history: digging through a long session for one tool call is painful, and there are no cost stats.

Method 3: Read the raw JSONL file

Sessions are stored as JSONL at ~/.claude/projects/<project>/<sessionId>.jsonl — one JSON object per line. You can inspect them with any editor or the command line:

# Extract all user prompts with jq
cat ~/.claude/projects/-Users-you-myproject/<sessionId>.jsonl \
  | jq -r 'select(.type=="user") | .message.content'

The raw file is the most complete source (token usage, git branch, timestamps and other metadata), but readability is poor — which is exactly why graphical viewers exist.

FAQ

Does viewing history upload my code?
No. CCViewer parses and renders everything in your browser; no network request ever carries session content. You can verify this yourself in the DevTools Network panel.
Can I still see compacted parts of a session?
Yes. Compaction summaries and subsequent messages live in the same JSONL file; the viewer shows summaries as injected context, visible via the "System/Injected" toggle.
Does it work on mobile?
Yes — CCViewer is a responsive web page. The session files live on your computer though, so you first need to copy the .jsonl to your phone (e.g. via iCloud/cloud drive) and open it in a browser.
