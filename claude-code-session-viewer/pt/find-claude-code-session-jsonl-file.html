Como encontro a localização do arquivo JSONL de uma sessão do Claude Code?

Atualizado 2026-10-12 · CCViewer Central de Ajuda · Aplica-se ao Claude Code 2.x

Todos os arquivos de sessão ficam num diretório fixo: ~/.claude/projects/. Com o sessionId, a localização leva segundos; sem ele, dá para buscar por conteúdo ou data.

Primeiro, entenda a nomenclatura dos diretórios

Cada subdiretório de ~/.claude/projects/ corresponde a um projeto (diretório de trabalho). O nome é derivado do caminho do projeto: os caracteres /, _ e outros não alfanuméricos são trocados por hífens -. Por exemplo:

Caminho do projeto              Diretório da sessão
/Users/you/Documents/my_app      →  -Users-you-Documents-my-app
/home/you/projects/shop-api      →  -home-you-projects-shop-api

Cada sessão é um arquivo: <sessionId>.jsonl (um UUID como 9a1b2c3d-…).

Caso 1: você sabe o sessionId — find direto

find ~/.claude/projects -name "<sessionId>.jsonl"

De onde vem o sessionId? O mais fácil é digitar o comando de barra /status na conversa — a saída inclui o Session ID atual. Também dá para pegá-lo na lista do claude --resume, em mensagens de erro ou no campo "Session ID" da barra lateral do visualizador.

Caso 2: sem sessionId — buscar por conteúdo

Se lembra de algo da conversa (por ex. sua pergunta original), use grep:

# Buscar palavra-chave em todas as sessões e listar arquivos
grep -l "consertar a página de login" ~/.claude/projects/*/*.jsonl

# Buscar só num diretório de projeto
grep -l "consertar a página de login" ~/.claude/projects/-Users-you-Documents-my-app/*.jsonl

Caso 3: achar sessões recentes por data

# Listar os 10 arquivos de sessão modificados mais recentemente
ls -t ~/.claude/projects/*/*.jsonl | head -10

O jeito gráfico: deixe o CCViewer fazer

Não quer digitar comandos? Dicas macOS: abrir pastas ocultas

  • No Finder, pressione ⌘⇧G, digite ~/.claude/projects e Enter;
  • Nos diálogos de arquivos, ⌘⇧. revela pastas ocultas (diretórios começados com . são invisíveis por padrão).

Perguntas frequentes

Por que não encontro o diretório ~/.claude?
Porque começa com ponto e fica oculto por padrão. No Finder, ⌘⇧G e digite o caminho, ou ⌘⇧. para mostrar arquivos ocultos; no terminal, ls -la ~/.claude sempre funciona.
Há muitos jsonl num projeto — qual é o meu?
Um arquivo equivale a uma sessão. Filtre por data de modificação (ls -t) ou conteúdo (grep -l); ou importe a pasta toda com o CCViewer, que mostra título e estatísticas de cada sessão para distinguir de relance.
Qual é o caminho no Windows?
Mesma estrutura no seu perfil de usuário: %USERPROFILE%\\.claude\\projects\\<projeto>\\<sessionId>.jsonl.
