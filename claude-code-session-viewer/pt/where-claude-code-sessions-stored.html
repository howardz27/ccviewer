Onde as informações de histórico das sessões do Claude Code são salvas?

Atualizado 2026-10-12 · CCViewer Central de Ajuda · Aplica-se ao Claude Code 2.x

Resposta curta: tudo fica salvo localmente sob ~/.claude/projects/ como arquivos JSONL — sem sincronização em nuvem, sem histórico de sessão amarrado à conta.

Estrutura de diretórios

~/.claude/
├── projects/                     # ← todo o histórico de sessões está aqui
│   ├── -Users-you-Documents-app/ #   um diretório por projeto (caminho convertido)
│   │   ├── 9a1b2c3d-….jsonl     #     um arquivo por sessão
│   │   └── 7c2d3e4f-….jsonl
│   └── -home-you-shop-api/
│       └── …
├── claude.json                   # configuração global (MCP, tema, estado por projeto)
└── … (cache, logs, estatísticas e outros arquivos auxiliares)

Regra de nome dos diretórios de projeto: todo caractere não alfanumérico (/, _, …) do caminho vira -. Por isso, todas as sessões de um projeto se agrupam num único diretório — é também a base do "agrupar por projeto" dos visualizadores.

O que há dentro de um arquivo JSONL

JSONL = um objeto JSON independente por linha. Um arquivo de sessão registra a conversa completa em ordem cronológica. Principais tipos de entrada:

typeConteúdo
userSua entrada (texto / imagens) e resultados de ferramentas devolvidos
assistantRespostas do modelo: texto, blocos de raciocínio, chamadas tool_use e uso de tokens
systemEventos do sistema (hooks etc.)
summary / ai-titleResumo da sessão e título gerado automaticamente
cost-stateInstantâneo de custo e uso (custo total, linhas ±, duração de API)

Cada entrada também traz metadados: timestamp, cwd (caminho do projeto), gitBranch, version, sessionId etc. Ou seja, o arquivo de histórico é mais completo do que o terminal mostra — raciocínio, parâmetros e resultados brutos de cada ferramenta e o consumo de tokens estão lá dentro.

O que isso significa para você

  • A privacidade está nas suas mãos: os arquivos nunca saem da sua máquina. Em contrapartida, faça backup de ~/.claude/projects/ antes de trocar de máquina ou reinstalar, ou o histórico se perde;
  • Os arquivos podem ser sensíveis: as sessões contêm trechos de código-fonte, caminhos, saídas de comandos e até segredos — não compartilhe .jsonl de qualquer jeito nem os publique;
  • O tamanho cresce: após meses de uso pesado, uma sessão pode chegar a vários (ou dezenas de) MB e o diretório inteiro a centenas de MB — é normal.

Como ler esse histórico com conforto

Ler JSONL bruto é um sacrifício. Abra o diretório com o CCViewer (arrastar a pasta inteira é suportado): as sessões se agrupam por projeto, e Markdown, blocos de raciocínio, chamadas de ferramenta e estatísticas de custo são renderizados graficamente — com a análise acontecendo só no seu navegador, preservando a propriedade "os dados nunca saem desta máquina".

Perguntas frequentes

O histórico do Claude Code é enviado aos servidores da Anthropic?
Os arquivos de sessão ficam no ~/.claude/projects/ local e não são armazenados separadamente na nuvem. Claro, durante uma conversa o conteúdo é processado via API — isso é inerente ao uso do modelo —, mas os arquivos de histórico são arquivos locais sob seu controle total.
Como apagar o histórico de sessões?
Basta excluir o arquivo .jsonl correspondente (ou o subdiretório inteiro do projeto); a sessão desaparece da lista de resume. Antes, confirme que não precisa de backup.
~/.claude/projects e ~/.claude.json são a mesma coisa?
Não. O ~/.claude.json (ou claude.json) é o arquivo de configuração global (servidores MCP, tema etc.); o histórico de sessões vive nos .jsonl sob ~/.claude/projects/.
