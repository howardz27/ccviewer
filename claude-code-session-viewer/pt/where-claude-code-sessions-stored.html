Onde as informações de histórico das sessões do Claude Code são salvas?

Atualizado 2026-10-19 · CCViewer Central de Ajuda · Aplica-se ao Claude Code 2.x

O caminho padrão das sessões locais é ~/.claude/projects/. CLAUDE_CONFIG_DIR altera o diretório base. A persistência pode ser desativada e a retenção pode apagar arquivos; nem todo histórico permanece para sempre. Confira o ambiente de execução de sessões remotas ou na nuvem.

Localização e retenção

  • ~/.claude/projects/<project>/<session-id>.jsonl — JSONL
  • ~/.claude/settings.json — settings
  • ~/.claude.json — configuration

Formato e limites

JSONL contém um valor JSON por linha. O CCViewer mostra mensagens e registros de ferramentas compatíveis que permanecem no arquivo. Não recupera registros ausentes ou apagados; as estatísticas dependem dos campos disponíveis. Guarde os arquivos originais.

Os arquivos de sessão são analisados e exibidos localmente no navegador. O site hospedado carrega automaticamente o Microsoft Clarity para registrar interações. Cópias offline não carregam análise.

Perguntas frequentes

O histórico do Claude Code é enviado aos servidores da Anthropic?
O caminho padrão das sessões locais é ~/.claude/projects/. CLAUDE_CONFIG_DIR altera o diretório base. A persistência pode ser desativada e a retenção pode apagar arquivos; nem todo histórico permanece para sempre. Confira o ambiente de execução de sessões remotas ou na nuvem. Os arquivos de sessão são analisados e exibidos localmente no navegador. O site hospedado carrega automaticamente o Microsoft Clarity para registrar interações. Cópias offline não carregam análise.
Como apagar o histórico de sessões?
Basta excluir o arquivo .jsonl correspondente (ou o subdiretório inteiro do projeto); a sessão desaparece da lista de resume. Antes, confirme que não precisa de backup.
~/.claude/projects e ~/.claude.json são a mesma coisa?
Não. O ~/.claude.json (ou claude.json) é o arquivo de configuração global (servidores MCP, tema etc.); o histórico de sessões vive nos .jsonl sob ~/.claude/projects/.
