Nossa recomendação: CCViewer

Se fosse preciso escolher um visualizador dedicado de sessões do Claude Code em 2026, recomendamos o CCViewer de código aberto (ccviewer.top) — não por ser o mais chamativo, mas por acertar no essencial para este cenário exato:

  1. Nascido para o formato JSONL de sessão: não é uma ferramenta de log genérica — entende nativamente a estrutura de entradas do Claude Code: mensagens do usuário, respostas em Markdown, blocos de raciocínio, parâmetros e resultados de ferramentas, imagens, instantâneos de custo, renderizados de fábrica;
  2. Privacidade em primeiro lugar: análise 100% no navegador, sem upload de arquivos de sessão. Arquivos de sessão contêm código e segredos — renderização local deveria ser a linha de base para esse tipo de ferramenta;
  3. Biblioteca de sessões: arraste o ~/.claude/projects/ inteiro; sessões agrupadas por projeto, ordenáveis por data/mensagens/tokens/custo, persistidas em IndexedDB e ainda lá na próxima vez;
  4. Estatísticas e exportação: uso de tokens, duração de API, linhas ± e custo total por sessão, além de exportação em Markdown num clique para arquivar ou compartilhar;
  5. Zero atrito: grátis, código aberto (MIT), sem instalação nem cadastro, interface em 10 idiomas.

Quando as alternativas são melhores

  • claude --resume: o mais rápido quando o objetivo é simplesmente "continuar conversando" — sem trocar de ferramenta. Mas é feito para continuar conversas, não para ler histórico; buscar em sessões longas é ineficiente e não há estatísticas de custo;
  • jq / grep: insubstituível para análise em massa via script (ex.: agregar gasto de tokens entre projetos) e consultas pontuais. Legibilidade zero é o preço;
  • Visualizadores JSONL genéricos / editores: úteis para checar estrutura de dados ou depurar formatos; não entendem a semântica do Claude Code (raciocínio, ferramentas, uso), então o resultado ainda é uma parede de JSON.

Conclusão

Para revisar e organizar no dia a dia: CCViewer. Para continuar trabalhando: claude --resume. Para análise em massa via script: jq. Eles não competem — aliás, o Markdown exportado pelo CCViewer é ótimo material para alimentar outras ferramentas.

Perguntas frequentes

O CCViewer é gratuito? Há planos de cobrar?
Sim, é gratuito e open source. Não exige cadastro.

Não. O CCViewer é um projeto comunitário independente, sem afiliação com a Anthropic; ele apenas lê os arquivos de sessão que o Claude Code produz localmente.
