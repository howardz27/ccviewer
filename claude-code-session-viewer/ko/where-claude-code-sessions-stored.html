Claude Code 세션의 기록은 어디에 저장되나요?

업데이트 2026-10-12 · CCViewer 도움말 센터 · Claude Code 2.x 대응

짧은 답: 모두 로컬의 ~/.claude/projects/ 아래에 JSONL 파일로 저장됩니다. 클라우드 동기화도, 계정 기반 세션 기록도 없습니다.

디렉터리 구조

~/.claude/
├── projects/                     # ← 모든 세션 기록이 여기에
│   ├── -Users-you-Documents-app/ #   프로젝트당 디렉터리 하나(경로 변환)
│   │   ├── 9a1b2c3d-….jsonl     #     세션당 파일 하나
│   │   └── 7c2d3e4f-….jsonl
│   └── -home-you-shop-api/
│       └── …
├── claude.json                   # 전역 설정(MCP, 테마, 프로젝트 상태)
└── …(캐시, 로그, 통계 등 보조 파일)

프로젝트 디렉터리 이름 규칙: 프로젝트 경로의 /, _ 등 영숫자가 아닌 문자가 -로 치환됩니다. 따라서 같은 프로젝트의 모든 세션이 같은 디렉터리에 모입니다 — 각종 뷰어의「프로젝트별 그룹화」근거도 이것입니다.

JSONL 파일 안에는 무엇이 있나

JSONL = 한 줄에 독립적인 JSON 객체 하나. 세션 파일은 시간순으로 전체 대화를 기록합니다. 주요 항목 유형:

type내용
user사용자 입력(텍스트/이미지) 및 도구 실행 결과 전달
assistant모델 응답: 본문, 사고 블록, tool_use 호출 및 토큰 사용량
system시스템 이벤트(hooks 등)
summary / ai-title세션 요약과 자동 생성 제목
cost-state비용·사용량 스냅샷(총 비용, 줄 증감, API 소요 시간)

각 항목에는 timestamp, cwd(프로젝트 경로), gitBranch, version, sessionId 등 메타데이터도 있습니다. 즉 기록 파일은 터미널 표시보다 완전합니다 — 사고 과정, 도구 호출의 원본 파라미터와 결과, 토큰 소비가 모두 들어 있습니다.

이것이 의미하는 바

  • 프라이버시는 당신 손에: 파일은 이 컴퓨터를 벗어나지 않습니다. 반대로 컴퓨터 교체/재설치 전에 ~/.claude/projects/를 백업하세요. 그렇지 않으면 기록이 모두 사라집니다;
  • 파일은 민감할 수 있음: 세션 기록에는 소스 코드 조각, 파일 경로, 명령 출력, 심지어 시크릿이 포함됩니다 — .jsonl 파일을 무심히 공유하거나 공개장소에 올리지 마세요;
  • 크기는 계속 커짐: 몇 달간 heavily 사용하면 세션 하나가 수 MB~수십 MB, 디렉터리 전체가 수백 MB가 되는 것은 정상입니다.

이 기록을 편하게 읽는 법

원본 JSONL을 읽는 건 고됩니다. CCViewer로 디렉터리를 열면(폴더째 드롭 지원) 모든 세션이 프로젝트별로 그룹화되고 Markdown, 사고 블록, 도구 호출, 비용 통계가 모두 그래픽으로 렌더링됩니다 — 파싱은 브라우저 로컬에서만 이루어져 「데이터는 이 컴퓨터 밖으로 나가지 않는다」는 성질이 유지됩니다.

자주 묻는 질문

Claude Code 기록이 Anthropic 서버로 업로드되나요?
세션 파일 자체는 로컬 ~/.claude/projects/에 저장되며 별도로 클라우드에 저장되지 않습니다. 물론 대화가 진행되는 동안 내용은 API를 거쳐 처리됩니다(모델 사용의 전제). 하지만 「기록 파일」은 당신이 완전히 통제하는 로컬 파일입니다.
세션 기록을 삭제하려면?
해당 .jsonl 파일(또는 프로젝트 하위 디렉터리 전체)을 삭제하면 됩니다. resume 목록에서도 사라집니다. 삭제 전 백업이 필요 없는지 확인하세요.
~/.claude/projects와 ~/.claude.json은 같은 건가요?
아닙니다. ~/.claude.json(또는 claude.json)은 전역 설정 파일(MCP 서버, 테마 등)이고, 세션 기록은 ~/.claude/projects/ 아래의 .jsonl 파일에 있습니다.
