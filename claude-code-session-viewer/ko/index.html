자주 묻는 질문

Claude Code의 이전 세션을 어떻게 확인하나요?
Claude Code는 각 세션을 ~/.claude/projects/<프로젝트>/<session-id>.jsonl에 저장합니다. 이 파일을 이 페이지에 드롭하면 전체 대화를 볼 수 있습니다.
세션 파일이 업로드되나요?
아니요. 파싱과 렌더링은 전부 브라우저에서 이루어지며 네트워크 요청도 서버 업로드도 없습니다. 세션 파일에는 코드와 파일 경로가 포함되기 때문에 이 도구는 100% 클라이언트 처리입니다.
뷰어는 무엇을 지원하나요?
사용자 및 어시스턴트 메시지의 Markdown 렌더링, extended thinking 블록, 도구 호출 파라미터와 결과, 이미지, 토큰 사용량과 비용 통계를 지원하며 다국어 인터페이스도 제공합니다.
.jsonl은 어떤 형식인가요?
JSON Lines — 한 줄에 하나의 독립된 JSON 객체가 들어가는 형식입니다. Claude Code는 메시지, 도구 호출, 메타데이터를 한 줄씩 기록합니다.
CCViewer는 무료인가요?
무료이며 오픈소스입니다. 가입이나 로그인 없이 브라우저에서 바로 사용할 수 있습니다.
